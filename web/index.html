System noise temperature · zenith

Loading receiver temperatures…

All seven receiving channels (RX 0–6); the transmitter reference is excluded. Dense, detection-independent zenith noise power divided by each channel’s zenith-only fitted gain gives measured Tsys = P/G. The fit is P = G(Tsky + Trec), using GSM2008 and the one-way module pattern. Absolute temperatures are provisional: colored-noise response and interference can bias the calibration.

About the meteor extension

PANSY is the Program of the Antarctic Syowa MST/IS Radar. The meteor extension was developed with the PANSY team, IAP Kühlungsborn and UiT The Arctic University of Norway. Co-investigators: Juha Vierinen, Jorge L. Chau, Nico Pfeffer, Devin Huyghebaert and Daniel Kastinen. Official PANSY project ↗

All plots are interactive Rustplotlib (Rust/WebAssembly; WebGL for the PMSE field). No historical animations or Matplotlib plot images are loaded. Scroll to zoom, drag a zoom box, Shift-drag to pan, double-click to reset. Refreshes retain the last successfully received data if the link is delayed.
